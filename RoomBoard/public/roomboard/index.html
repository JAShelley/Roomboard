Install and update help Step-by-step browser extension install and refresh instructions.
What this does
These add-ons let you use RoomBoard tools directly inside your browser.

Step 1: Download the add-on
Click the download button for the add-on you want. A zip file will be saved to your computer.

Step 2: Open your Downloads folder
Find the file you just downloaded.

Step 3: Unzip the file
Right-click the file and select Extract, Open, or Unzip depending on your computer.

Step 4: Move the folder somewhere easy to find
Your Desktop is usually easiest.

Step 5: Open Chrome extensions
Open Google Chrome and go to chrome://extensions.

Step 6: Turn on Developer Mode
Use the toggle in the top right corner.

Step 7: Add or update the add-on
Click “Load unpacked” and select the unzipped folder. If you are updating, replace the old folder first and then click Reload on the extension card.

Step 8: Refresh your page
Return to RoomBoard or your scheduler page and refresh the tab.

Troubleshooting
Make sure you unzipped the file, selected the folder instead of the zip, and reloaded the extension after updates.
