Install the Pulse addon

Step 1: Download the addon
Click the “Pulse addon zip” button above. The file will download to your computer.

Step 2: Open Downloads
Find the downloaded zip file in your Downloads folder.

Step 3: Unzip it
Right-click the zip and extract it so you have a normal folder.

Step 4: Open Chrome extensions
Open Google Chrome and go to chrome://extensions.

Step 5: Turn on Developer Mode
Use the Developer Mode toggle in the top right.

Step 6: Load the addon
Click “Load unpacked” and choose the unzipped Pulse addon folder.

Step 7: Allow file access if needed
If RoomBoard is opened as a file:// page, open the extension details page and enable “Allow access to file URLs.”

Step 8: Refresh your tabs
Refresh both the Pulse scheduler tab and the RoomBoard tab after loading or updating the addon.

How to update it later
Download the newest zip, unzip it, replace the old addon folder, then go back to chrome://extensions and click Reload on the Pulse addon.
