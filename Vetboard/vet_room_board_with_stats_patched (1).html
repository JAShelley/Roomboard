What this does
This add-on lets you use RoomBoard tools directly inside your browser.

Step 1: Download the add-on
Click the “Download Add-On” button. A file will be saved to your computer (it may look like a zipped file).

Step 2: Open your Downloads folder
Open your Downloads and find the file you just downloaded.

Step 3: Unzip the file
Right-click the file and select:
“Extract” (Windows)
“Open” or “Unzip” (Mac)
This will create a new folder.

Step 4: Move the folder to your Desktop
Click and drag the unzipped folder onto your Desktop so it is easy to find.

Step 5: Open Chrome extensions
Open Google Chrome.
Click the address bar at the top, type: chrome://extensions
Press Enter.

Step 6: Turn on Developer Mode
In the top right corner of the page, turn on “Developer Mode.”

Step 7: Add the add-on
Click “Load unpacked.”
Select the folder you moved to your Desktop.
Click Open.

You’re done
The add-on is now installed and ready to use.

Troubleshooting
If it doesn’t work:
Make sure you unzipped the file
Make sure you selected the folder, not the zip file
Make sure you are using Google Chrome

How to Update the RoomBoard Add-On

What this does
This updates your add-on to the newest version.

Step 1: Download the updated add-on
Click the “Download Add-On” button. A file will be saved to your computer (it may look like a zipped file).

Step 2: Open your Downloads folder
Open your Downloads and find the file you just downloaded.

Step 3: Unzip the file
Right-click the file and select:
“Extract” (Windows)
“Open” or “Unzip” (Mac)
This will create a new folder.

Step 4: Move the folder to your Desktop
Click and drag the unzipped folder onto your Desktop.

Step 5: Replace the old folder
If you already have a RoomBoard folder on your Desktop:

Drag the new folder onto the Desktop
When asked, click “Replace” (Windows) or “Replace” / “Merge” (Mac)

Step 6: Reload the add-on
Open Google Chrome.
Type: chrome://extensions in the address bar and press Enter.
Find the RoomBoard add-on and click the Reload button.

Step 7: Refresh your page
Go back to your webpage and refresh it.

You’re done
The add-on is now updated and ready to use.

Troubleshooting
If it doesn’t update:
Make sure you replaced the old folder
Make sure you clicked Reload on the extension
Try refreshing the webpage again
Make sure you are using Google Chrome
